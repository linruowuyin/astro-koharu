# 震荡期的操作方法

大部分时候不需要等突破再买，以及站上5日线再买
震荡期的做法应当是低吸支撑位，做超跌反弹。
跌了买一买 涨了卖一卖

![image-20260614234059145](https://img.lrwy.de5.net/file/1781451672617_20260614234059438.webp)

这种例子很多，随便找两个熟悉的

启动上涨-主升浪的阶段：

主升期判断：五日线与十日线之上，股价持续上涨。

1. 低吸五日线（短期均线），沿着五日线尽量多持股
2. 不破位，不破大趋势就不卖
3. 破五日线可以适当减仓降低成本
4. 主升浪可以买突破，可以买站上五日线，适当追高

**主升浪阶段可以追涨杀跌，震荡阶段是完全相反的，要高抛低吸**

![image-20260614234827143](https://img.lrwy.de5.net/file/1781452122813_20260614234827465.webp)

比如说沪电股份，这个走势站上五日线去买是非常难受的，策略是低吸下方的缺口（箱体下沿），摸了之后去买可能更好，这不是弱，是在震荡洗盘，没有放量跌破之类明显的出货信号需要额外注意之外可以放心持股，不要特别机械化死板一旦跌破某个均线就马上卖，可以分批用次数来弥补不确定性

震荡阶段

震荡期判断：五日线与十日线之下，股价波动较大。

1. 大部分时候不需要等突破再买，以及站上5日线再买，低吸箱体或者均线支撑
2. 震荡期不是追高的，是低吸的。震荡期的做法应当是低吸支撑位，做超跌反弹。
3. 跌了买一买 涨了卖一卖
