# 稀土

> 稀土并非单一物质，而是**17种稀土元素的统称**，包含镧、铈、镨、钕等轻稀土，以及钐、铕、铽、镝等中重稀土。它之所以叫“稀土”，并非因为稀有到罕见，而是因为早期开采难度大、分布零散、难以提纯，外观类似“土状”，因此得名
>
> A股炒作时轻重稀土大多数时候"同板块联动"，但资金经常按催化因素做"选择性分化炒作"——重稀土（中国稀土/广晟有色）和轻稀土（北方稀土/包钢股份）会被区别对待，涨幅和节奏可以明显不同。



轻稀土和重稀土是按**原子序数、离子半径及地球化学性质**对17种稀土元素的划分（与金属实际密度无关），二者在资源储量、矿床类型、用途和战略价值上差异显著

| **类别**           | **别名** | **包含元素（共17种中去钪）**                                 | **划分依据**                                   |
| :----------------- | :------- | :----------------------------------------------------------- | :--------------------------------------------- |
| **轻稀土（LREE）** | 铈组稀土 | La镧、Ce铈、Pr镨、Nd钕、Pm钷(放射性)、Sm钐、Eu铕 — **7种**   | 原子序数较低(57–63)，离子半径大，碱性较强      |
| **重稀土（HREE）** | 钇组稀土 | Gd钆、Tb铽、Dy镝、Ho钬、Er铒、Tm铥、Yb镱、Lu镥 + **Y钇** — **9种** | 原子序数较高(64–71+39)，离子半径小，性质更稳定 |

| **对比项**   | **轻稀土**                                                   | **重稀土**                                                   |
| :----------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **地壳丰度** | 相对高（占稀土总储量≈90%）                                   | 极稀缺（≈10%，Tb/Dy尤甚）                                    |
| **典型矿床** | 碳酸岩型/氟碳铈矿、独居石（可大规模露天开采）                | **离子吸附型稀土矿**（稀土离子吸附于风化壳黏土），需化学浸取，环保要求高 |
| **中国分布** | **"北轻"**——内蒙古白云鄂博（全球最大）、四川牦牛坪、山东微山 | **"南重"**——江西赣州、福建、广东、广西离子型矿（全球重稀土主要供应源） |
| **全球分布** | 美（芒廷帕斯）、澳（韦尔德山）、俄、巴等也有                 | 高度集中在中国南方，少量在缅甸/越南，他国几乎无经济可采矿床  |

| **类别**   | **核心应用方向**                                 | **关键元素与用途举例**                                       |
| :--------- | :----------------------------------------------- | :----------------------------------------------------------- |
| **轻稀土** | 新能源、基础工业、大宗消费品（用量大、偏规模化） | **Nd/Pr**→钕铁硼永磁（新能源车电机、风电）；**Ce**→玻璃抛光/汽车尾气催化；**La**→镍氢电池、光学玻璃、石化催化剂 |
| **重稀土** | 高端制造、军工、精密电子（用量小、不可替代性强） | **Dy/Tb**→添加入钕铁硼提升高温矫顽力（高性能电机、雷达、导弹制导）；**Y**→激光晶体、超导、荧光粉；**Eu**→红光荧光粉 |
